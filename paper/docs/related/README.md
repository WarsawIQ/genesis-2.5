# Recent SoftwareX articles, for calibrating the revision's style

submitted to), four of them neuroinformatics, kept here as the reference set the
revision's structure and register were checked against (October 2026). All five are
open access under CC BY 4.0; each PDF below is the publisher's version, obtained from
the source named beside it, and carries its own attribution and copyright lines.
