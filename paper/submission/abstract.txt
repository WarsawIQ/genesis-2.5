GENESIS is a long-established compartmental neural simulator. We release GENESIS 2.5, adding opt-in OpenCL and CUDA backends for the Hodgkin-Huxley channel-update path and hines_tree_eliminate, a GPU Hines tree-elimination kernel for dendritic trees, leaving every existing model, script and MPI workflow unchanged. On cluster hardware the accelerator reaches 57x end-to-end speedup on a 160,000-compartment population, matching the fp64 CPU solver to about 1e-7 V. Measured against other simulators on one node, it runs the Vogels-Abbott COBAHH benchmark 2.3x faster than CoreNEURON on a single CPU core, and on the GPU it overtakes the GPU-native Arbor beyond 18-64 ms of simulated time depending on the card; CoreNEURON's GPU stays 1.23x ahead on that spiking benchmark. Networks of synaptically coupled spiking neurons now reach the accelerator. A solver could track only one spiking cell, so such a network needed one solver per cell - four thousand of them for the benchmark used here - and that overhead dominated. A solver can now track a whole layer, which is 1.4x faster on the CPU before any GPU is involved. On the GPU the same network runs no faster than on the CPU: the cells exchange spikes at every timestep, so the work cannot be batched and each of the 100,000 steps pays for a separate GPU call. The release also makes O(n^2) model construction linear and repairs seven defects, three of them in the solver GENESIS 2.4 ships.
