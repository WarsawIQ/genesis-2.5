# Audit of cluster-only scripts, 2026-09-29

On 2026-09-29 every `*.sh`, `*.py` and `*.g` changed since 2026-08-01 in the home directory
on the UMCS login node was compared, by SHA-256, with the files in this repository. The ones
below existed only on the cluster. Each is listed with its checksum as found, what it
produced, and what happened to it. Every file marked "imported" (and the three still to be
decided) is committed unchanged in `as-found/`, so its checksum can be compared with this
table (`cd as-found && sha256sum -c ../AS_FOUND.sha256`). The working versions at the paths
named in the last column were derived from those copies in later commits, so `git log -p`
shows every change made to them.

Scripts that were already in the repository with identical content (the Arbor, crossover,
vmcross, profiling and CoreNEURON CPU harnesses) are not listed. The LSM project's files from
2026-09-16 (`neuron.g`, `construct_serial.g`, `run_configuration.g`, `scan_serial.g`,
`channels_tab.g`, `pparameters.g`, `lesion_*.g`) belong to another project and are out of scope.
