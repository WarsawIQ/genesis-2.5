GENESIS v2.6.2, Linux x86_64 binaries

Built from v2.6.2 (6699e792d46ae0d2757aa0b46be9368bf11f87ec) on inf03,
AlmaLinux 8.10 (Cerulean Leopard), ldd (GNU libc) 2.28, gcc (GCC) 8.5.0 20210514 (Red Hat 8.5.0-28).

bin/nxgenesis_nocl  CPU only; needs glibc and ncurses.
bin/nxgenesis_ocl   OpenCL 1.2 (any vendor's ICD, e.g. ROCm, Mesa rusticl, NVIDIA). It compiles
                    bin/hines/opencl/ocl_channel.cl at run time and finds it next to itself;
                    keep the two together or name the file in GENESIS_OCL_KERNEL. Without it
                    the backend says 'nie znaleziono ocl_channel.cl' and computes on the CPU.
bin/nxgenesis       CUDA; needs the NVIDIA driver and the CUDA 12 runtime (libcudart.so.12), and an OpenCL ICD loader (libOpenCL.so.1).
                    GPU code: native for sm_80 ; PTX for sm_80 , which the driver
                    compiles for newer GPUs. GPUs older than the lowest of these do not run it.

Run from a directory holding a .simrc that puts startup/ on SIMPATH, as genesis/startup
is used in a source build (see README.md of the repository), e.g.
    setenv SIMPATH . <this directory>/startup
Choose precision and batching at run time: GENESIS_GPU_PRECISION=fp32|fp64,
GENESIS_CUDA_MULTILOOP=<K>, GENESIS_OCL_MULTILOOP=<K>. Known issues: KNOWN_ISSUES.md
in the repository.
